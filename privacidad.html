Jarvis

Política de privacidad

Última actualización: 12 de noviembre de 2026.

Jarvis es un programa que se instala y se ejecuta en la computadora de cada persona. No tiene servidores propios ni cuentas de usuario: quien lo desarrolla no recibe, no almacena ni puede ver los datos de quienes lo usan.

Qué datos usa Jarvis

  • Calendario de Google (solo lectura): si conectás tu cuenta, Jarvis lee los eventos de los calendarios que elijas (título, hora y lugar) para avisarte antes de que empiecen y para contestar preguntas sobre tu agenda. No crea, modifica ni borra eventos.
  • Mensajes y mails: los que vos conectes (WhatsApp, Gmail) se leen en tu computadora para mostrarte avisos. Jarvis no lee el cuerpo de los mails.
  • Voz y micrófono: el audio se procesa en tu computadora. Si activás un servicio de inteligencia externo, solo se envía el texto de lo que pediste a ese servicio, no el audio.
  • Pantalla y sonido para clips: los clips se guardan como archivos en tu computadora y solo salen de ella si vos pedís mandarlos.

Dónde se guardan

Todo (configuración, llaves de acceso, historial y clips) queda en una carpeta local junto al programa. Jarvis no envía esos datos a ningún servidor del desarrollador. Para dejar de usarlo y borrar todo alcanza con eliminar esa carpeta.

Uso de la información de Google

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Los datos del calendario se usan únicamente para las funciones descritas arriba, no se comparten con terceros, no se usan para publicidad y no los lee ninguna persona.

Cómo retirar el permiso

En Jarvis, Ajustes → Cuentas → Calendario → “Desconectar”. También podés quitar el acceso desde myaccount.google.com/permissions.
